# LESN: Who's Good AU lessons

Short, hands-on lessons that run live in the browser. Plain static files, no build step.

- `index.html`: the lessons list (one card per lesson)
- `3d-box/`: **Learn 3D with the Who's Good AU Box** (three.js, 7 lessons)

New lesson = a new folder with its own `index.html`, plus a card on the list page.
Intended address: `https://learn.whosgood.au` (GitHub Pages).
